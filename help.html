Quick Keys

Select one or more messages, then use these shortcuts. Press Esc to close this window.

Inside the tag and folder pickers

typefilter the list (the first letters of a word are enough)
↑ ↓move the highlight
Enterapply to the selected messages. Tags toggle on and off; a folder moves them there
Shift+Entertag picker only: apply and keep the picker open, to add several tags
Escclose without doing anything

Thunderbird's own shortcuts keep working (A archives, Delete deletes, 1 to 9 toggle the first nine tags).
To change these shortcuts: Add-ons and Themes → the gear menu → Manage Extension Shortcuts.
